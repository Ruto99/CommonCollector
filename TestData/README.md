# テストデータ

LabelCollector のエクセル読み込みを試すためのファイルです。中の会社名・人名・電話番号はすべて架空のものです。

| フォルダ | キー列名 | 内容 |
|---|---|---|
| `Excel/部品一覧` | `ID`、`部品番号` | 部品の一覧。サブフォルダ `追加分`・`旧形式` のファイルも読み込まれます。`旧形式` のファイルだけキー列名が `部品番号` |
| `Excel/顧客リスト` | `顧客ID` | 顧客の一覧 |
| `Excel/在庫表` | `ID` | 2段見出し（1行目が大項目、2行目が列名）と結合セルの例。見出しの段数を 2 にして読む |

## 試し方

1. 左のエクスプローラーで右クリック →「新しい中間データ(.lc)を作成」で、空の中間データを作って開く
2. ツールバーの「＋ シート追加 ▾」→「📊 エクセルフォルダ」で `TestData/Excel/部品一覧` を選ぶ（キー列名は最初「ID」）
   → `旧形式` 以外のファイルの ID が読み込まれる
3. 右のプロパティで、キー列名に「＋ キー列名を追加」で `部品番号` を足す
4. 「取り込む列」の「列の候補を読み込む」で、部品名・型番・数量などの列を追加する
   - `旧形式` のファイルは列名が違う（品名・在庫）ので、「＋ 列を追加」で `品名 → 部品名`、`在庫 → 数量` を足すと同じ列にまとまる
5. 「🔄 このシートを更新」→ 表に列が増え、`旧形式` のファイル（P-101〜P-103）も読み込まれる
6. 「＋ データ元を追加」→「📗 エクセルファイル」で `TestData/Excel/顧客リスト/顧客一覧.xlsx` を足し、
   キー列名を `顧客ID`、取り込む列を `会社名` などにして更新 → 1つの表に部品と顧客の行が並ぶ

7. 「＋ シート追加 ▾」→「📊 エクセルフォルダ」で `TestData/Excel/在庫表` を選び、プロパティで「見出しの段数」を 2 にする
   → 「列の候補を読み込む」で `部品/名称`・`数量/在庫` のような列名が出る。`名称` や `在庫` のように下の段の名前だけでも指定できる
   → 縦に結合された「分類」「名称」の値が、結合範囲のすべての行に入る（チェックを外すと一番上の行だけ）

## 確認できること

- `部品一覧_2026.xlsx` の「機械部品」シートは、タイトル行の下（3行目）に見出しがある → 見出し行を自動で探して読み込む
- 「電気部品」シートの ID が空の行 → 読み飛ばす
- 「メモ」シートには ID 列が無い → 読み込まない
- `追加分/部品一覧_追加.xlsx` の `M-003` は重複 → ログに警告が出て、先に見つかったほうを使う
- 数値の ID（`1001`）→ `1001.0` ではなく `1001` として読み込む
- `旧形式/部品一覧_旧.xlsx` は見出しが `部品番号` → キー列名に `部品番号` を追加すると読み込む
- `在庫表/在庫表_2段見出し.xlsx` は、タイトル行の下に2段の見出しがあり、「ID」は縦に、「部品」「数量」は横に結合されている
  → 見出しの段数 2・見出しの行は自動のままで、正しい位置から読み込む
