# テストデータ

LabelCollector のエクセル読み込みを試すためのファイルです。中の会社名・人名・電話番号はすべて架空のものです。

| フォルダ | キー列名 | 内容 |
|---|---|---|
| `Excel/部品一覧` | `ID`、`部品番号` | 部品の一覧。サブフォルダ `追加分`・`旧形式` のファイルも読み込まれます。`旧形式` のファイルだけキー列名が `部品番号` |
| `Excel/顧客リスト` | `顧客ID` | 顧客の一覧 |

## 試し方

1. 左のエクスプローラーで右クリック →「新しい中間データ(.lc)を作成」で、空の中間データを作って開く
2. エクスプローラーでその `.lc` ファイルを選ぶと、右のプロパティウィンドウに中身が表示される
3. プロパティウィンドウ一番下の「＋ エクセルのシートを追加」でシートを追加し、
   フォルダに `TestData/Excel/部品一覧` を指定して「🔄 更新」（キー列名は最初「ID」）
   → `旧形式` のファイルは読み込まれない
4. 「＋ キー列名を追加」でキー列名に `部品番号` を足して、もう一度「🔄 更新」
   → `旧形式` のファイル（P-101〜P-103）も読み込まれる
5. そのシートの「＋ エクセルの指定を追加」で、フォルダに `TestData/Excel/顧客リスト`、
   キー列名に `顧客ID` を指定して、もう一度「🔄 更新」

## 確認できること

- `部品一覧_2026.xlsx` の「機械部品」シートは、タイトル行の下（3行目）に見出しがある → 見出し行を自動で探して読み込む
- 「電気部品」シートの ID が空の行 → 読み飛ばす
- 「メモ」シートには ID 列が無い → 読み込まない
- `追加分/部品一覧_追加.xlsx` の `M-003` は重複 → ログに警告が出て、先に見つかったほうを使う
- 数値の ID（`1001`）→ `1001.0` ではなく `1001` として読み込む
- `旧形式/部品一覧_旧.xlsx` は見出しが `部品番号` → キー列名に `部品番号` を追加すると読み込む
