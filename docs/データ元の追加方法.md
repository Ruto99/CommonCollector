# データ元の追加方法

LabelCollector は、データ元（どこから行を読むか）を後から追加できるように作られています。
組み込みのデータ元は次の3つです。

| 種類 | 設定クラス（Model） | 読み取り処理 |
|---|---|---|
| エクセルファイル | `Models/Sources/ExcelSourceSettings.cs` の `ExcelFileSourceSettings` | `Services/Sources/ExcelReaders.cs` の `ExcelFileReader` |
| エクセルフォルダ | `Models/Sources/ExcelSourceSettings.cs` の `ExcelFolderSourceSettings` | `Services/Sources/ExcelReaders.cs` の `ExcelFolderReader` |
| フォルダのファイル一覧 | `Models/Sources/FileListSourceSettings.cs` | `Services/Sources/FileListReader.cs` |

## 全体の仕組み

```
シート（SheetData）
 ├─ 手入力の列（ManualColumns）        … 画面で入力する列。更新しても消えない
 ├─ データ元の一覧（Sources）           … 種類が混ざっていてよい
 │    └─ SourceSettings（種類ごとの設定）
 │         ├─ Columns：取り込む列（元の列名 → 表の列名）
 │         └─ TableSourceSettings なら KeyColumns（キー列名の候補）・SheetName
 └─ 行（Rows：RowItem）
      ├─ Key（キー）・Origin（取得元）・State・LastSeen
      ├─ Values（自動の列：データ元から読んだ値）
      └─ Manual（手入力の列の値）
```

更新ボタンを押すと、次の順に処理されます。

1. シートのデータ元ごとに `DataSourceRegistry` から種類を探し、読み取り処理（`IDataSourceReader`）を作って `Read()` する
2. `RecordCombiner` が全データ元の行をキーで1つにまとめる（同じキーなら列を足し合わせる）
3. `RowMerger` が既存の行とキーで照合する（自動の列は入れ替え、手入力の列は残す。消えた行は「消えた行」として残す）

読み取り処理は「キー・取得元・列名→値」の一覧（`SourceRecord`）を返すだけです。まとめ・照合・保存・表示は共通の処理が行います。

## 新しいデータ元を追加する手順（例：CSV ファイル）

### 1. 設定クラスを作る（Models/Sources）

- `SourceSettings` を継承します。キー列で行を識別する表形式なら `TableSourceSettings` を継承すると、キー列名の候補とシート名が使えます。
- `[XmlType("Csv")]` のように、.lc に保存するときの名前を付けます。一度使い始めたら変えないでください。
- ファイルを指定するなら `IFileLocation`、フォルダなら `IFolderLocation` を実装します。追加時の場所選びと「…」ボタンが自動で使えるようになります。
- 値が変わったことを画面に知らせるため、プロパティは `Set(ref field, value)` で書きます。

```csharp
[XmlType("Csv")]
public class CsvSourceSettings : TableSourceSettings, IFileLocation
{
    private string _filePath = "";
    public string FilePath { get => _filePath; set => Set(ref _filePath, value); }

    [XmlIgnore] public string FileDialogFilter => "CSV (*.csv)|*.csv";
    [XmlIgnore] public override string Location => FilePath;
}
```

### 2. 読み取り処理を作る（Services/Sources）

`IDataSourceReader` を実装します。

- `Read()`：行を読んで `SourceRecord` の一覧を返します。
  - キーが空の行は返さないでください。
  - 値は `settings.Columns` の「元の列名」で探し、「表の列名」（`TargetName`）をキーにして入れます。
  - 読めないとき（ファイルが無いなど）は例外を投げてください。その場合、表は変わりません。
- `GetColumnNames()`：取り込める列の名前を返します。プロパティの「列の候補を読み込む」で使います。

```csharp
public class CsvReader(CsvSourceSettings settings) : IDataSourceReader
{
    public List<SourceRecord> Read() { /* CSV を読んで SourceRecord を作る */ }
    public IReadOnlyList<string> GetColumnNames() { /* 見出し行を返す */ }
}
```

### 3. 登録する

`Services/DataSourceRegistry.cs` の static コンストラクタ（組み込みとして足す場合）か、
`App.xaml.cs` の `OnStartup`（外から足す場合）で登録します。登録した順にメニューへ並びます。

```csharp
DataSourceRegistry.Register<CsvSourceSettings>("CSVファイル", "🧾",
    () => new CsvSourceSettings { KeyColumns = { new TextItem("ID") } },
    s => new CsvReader(s));
```

登録すると、次のものが自動で使えるようになります。

- ツールバーやメニューの「シート追加」、プロパティの「＋ データ元を追加」のメニュー
- .lc への保存と読み込み（`xsi:type="Csv"` として保存）
- 追加時の場所の選択（`IFileLocation` / `IFolderLocation` を実装した場合）

### 4. プロパティの編集欄を作る（PropertyPanel.xaml）

`PropertyPanel.xaml` の「データ元ごとの編集欄」に、設定クラスの型を指定した `DataTemplate` を1つ足します。
共通部品を組み合わせると簡単です。

- `TableKeyEditor`：シート名・キー列名の候補
- `ColumnsEditor`：取り込む列（「列の候補を読み込む」ボタン付き）
- `FolderLocationEditor`：フォルダの指定

```xml
<DataTemplate DataType="{x:Type ms:CsvSourceSettings}">
    <StackPanel>
        <!-- ファイルの指定（ExcelFileSourceSettings の編集欄と同じ形） -->
        ...
        <ContentControl Content="{Binding}" ContentTemplate="{StaticResource TableKeyEditor}" Focusable="False"/>
        <ContentControl Content="{Binding}" ContentTemplate="{StaticResource ColumnsEditor}" Focusable="False"/>
    </StackPanel>
</DataTemplate>
```

文字の入力欄には `LostFocus="Setting_LostFocus"`、チェックボックスには `Click="Setting_Changed"` を付けてください。
入力が終わったときに保存されます。

## 注意

- 設定クラスのプロパティ名と `[XmlType]` の名前は .lc の保存形式になります。変えると、以前の .lc の設定が読めなくなります。
- 登録されていない種類のデータ元が .lc に入っていると、その .lc は読み込めません。種類を削除するときは注意してください。
